# MetaFox 5.2.7

## What's new

**Release Date: TBD**

### **Core**

* UI/UX Improvements
* Frontend Web
    * Updated the primary color of several components for a more unified look.
    * Consistent border styling across all input fields.
    * Fixed unexpected text wrapping on some pages.
    * Rich Text Editor: Improved the layout and alignment of the Insert action dialogs.
* The storage cleanup job no longer times out when many files need to be removed.
* Verification codes are now invalidated when an account is deleted, even if its email or phone number is later reused.
* Fix bugs

### **Fresh Theme**

* UI/UX Improvements

### **Advertise**

* Users can now edit an ad while it is running, without having to stop or recreate it.

### **Announcement**

* Support uploading images to announcements.

### **Paid Content**

* Support paid content on **Live Video**.
* UI/UX Improvements
* Mobile layout - The Paid Content icon is now properly centered.
* Paid content items are now blurred in Saved Items until purchased.
* Closing the Set Price dialog no longer closes the Feed Composer.
* Fix bugs

### **In-App Purchase**

* Mobile apps now support purchasing **Activity Points** and **E-Wallet** packages.

### **Clips**

* Mobile apps - Support searching within the Clips app.
* Fix bugs

### **ChatPlus**

* Support sending **Voice Messages** on the web version.
* Fix bugs

### **ChatGPT Bot***

* Support new OpenAI models

### **Groups**

* UI/UX Improvements
* Improved the behavior when clicking the membership status label.

### **Photos & Videos**

* Mature content photos and videos are now properly blurred with a warning in Saved Items.
* Videos - Support adding videos from YouTube Live URLs.
* Fix bugs

### **Activity Points**

* Deleting a profile photo now correctly retrieves all earned points.
* Fix bugs

### **And,**

* There are many bug fixes, minor UI/UX Improvements, and updates for compatibility with MetaFox 5.2.7 on other apps, such as **Feed**, **Events**, **Live Videos**, **EWallet**, **Notifications**, **Mobile App**, etc.
