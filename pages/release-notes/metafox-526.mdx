# MetaFox 5.2.6

## What's new

**Release Date: TBD**

### **Paid Content (New App)**

* MetaFox 5.2.6 introduces support for paid content (Photo, Video) across the platform. This enables creators and administrators to monetize premium content more easily while delivering a smoother experience for users who purchase access.

### **Mobile & Platform Experience**

* Upgraded mobile app support to React Native 0.81 and improved compatibility with Android 16.
* Improved the user experience when viewing photo detail pages and interacting with touch gestures.
* Enhanced mobile reliability with fixes for crash and rendering issues affecting Android and iOS.
* Improved notification and menu interactions for a more consistent app experience on mobile devices.

### **Core**

* AdminCP menu configuration is now more flexible, allowing administrators to set applicable roles for menus.
* Added the ability to delete inactive members through the Inactive Members action flow.
* Improved the Welcome page user interface for a cleaner and more polished onboarding experience.
* Improved overall workflow and reliability around installation and app management.

### **Clips**

* Added support for searching and adding Clips on a user profile.
* Improved the upload workflow for Clips when a user exceeds the storage limit, making the process clearer and more reliable.
* Fixed issues related to clip settings and validation to ensure expected upload limits are enforced correctly.

### **Groups**

* Fixed an issue where public group joins could trigger unnecessary "Pending Group Join Request" emails to administrators.

### **ChatPlus & ChatGPT Bot**

* Fixed issues where opening a chat call could lead to an empty page.
* Improved chat input behavior by preventing unnecessary focus on the type bar when opening a chat box.
* Fixed the chatbot redirect issue that caused a 404 page when users clicked the chatbot avatar.

### **And,**

* There are many additional bug fixes, UI/UX improvements, and stability enhancements, including updates for **Groups**, **ChatPlus**, **ChatGPT Bot**, **Clips**, **Mobile**, and other platform areas.
