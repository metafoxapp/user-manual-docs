# MetaFox 5.2.5

**Release Date: TBD**

## What's new

### **Clips**

* **Clips Block in Activity Feed** – Clips now appear organically in the activity feed, giving users a fresh and engaging way to discover short videos without leaving their main feed. Available on both web and mobile.
* Fix bugs

### **ChatPlus**

* **Giphy Integration** – Users can now search and share animated GIFs directly from Giphy inside ChatPlus conversations. Available on both web and mobile for a more expressive and fun chat experience.
* **UI/UX Improvements**
    * The text input bar no longer auto-focuses when opening a chat box, reducing unintentional interactions.
* Fix bugs

### **E-Wallet**

* **Top-Up to Wallet** – Users can now conveniently add funds to their E-Wallet by purchasing top-up packages directly through the platform.
* Fix bugs

### **Friends**

* Improved data synchronization on the **Friend Suggestions** and **People You May Know** pages, ensuring users always see fresh and accurate recommendations.

### **Core**

* **Enhanced Source Code Security** – Critical security improvements have been applied across the platform to further protect your site and its data.
* **Improved Installation Wizard** – The installation process has been refined for a smoother and more reliable setup experience.
* Fix bugs

### **Groups**

* Improved performance when switching between tabs on a Group detail page that uses a custom slug.
* Improved the behavior when clicking on the membership status label for a more intuitive experience.
* Fix bugs

### **Pages**

* Improved performance when switching between tabs on a Page detail page that uses a custom slug.
* Fix bugs

### **And,**

* There are many additional bug fixes, minor UI/UX improvements, and stability updates across other apps and components in MetaFox 5.2.5, including **Events**, **Live Videos**, and more.
